Backend

TVer Japanese captions → English

Translates TVer's timed Japanese caption track in contextual batches. This avoids audio transcription and keeps the original timing.

gpt-5.6-terra is the recommended quality/latency balance for drama dialogue. OpenRouter text translation reuses the OpenRouter key below; choose a model that supports structured outputs. Direct gemini-3.5-flash-lite has a free tier. DeepL API Free provides 500k characters/month and accepts surrounding dialogue as unbilled context. Edge 148+ can translate entirely on-device, but does each cue independently.

OpenRouter (batch)

One call transcribes Mandarin and translates to English. Try google/gemini-3.1-flash-lite (cheap) or a Groq Whisper model.

OpenAI Realtime Translate (streaming, ~1s)

Purpose-built live translator (gpt-realtime-translate): audio in → English text out. Use OpenAI directly, or your Azure Foundry deployment.

API version is an Azure service version — use the literal word preview for preview models like gpt-realtime-translate. It is not the model's snapshot date.

Browser websockets can't send an api-key header. This uses the insecure-api-key subprotocol; if your Azure resource rejects it, mint an ephemeral key server-side and paste it above.

Gemini Live (streaming, ~1s)

Streaming needs a direct Google AI Studio key — OpenRouter cannot stream. This bypasses OpenRouter and bills Google directly.

Tuning

Lower = less lag, worse accuracy. ~3000 is a good start.
